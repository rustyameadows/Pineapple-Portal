# Global Locations (Global Venues)

## What this feature is
Global Locations are shared venue/location records managed once and reused across all events.

## Where to manage global locations
- Left sidebar (index/admin shell): **Locations**.
- Route: Settings-level global venue list.

## What you can manage in a global location record
- Location name
- Contact list (name/title/email/phone/notes)

## Where global locations are used
Inside each event under **Event Info → Locations**:
- Location name inputs support lookup/selection from global location records.
- This keeps names and contacts consistent across events.

## Safe-delete rule
A global location cannot be deleted while linked to one or more event location records.

## How an operator should use it
1. Create the venue/location once globally.
2. Reuse it in each event’s Locations page.
3. Control client visibility and item ordering at event level.
