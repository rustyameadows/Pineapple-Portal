# Approvals

## What this feature is
A full approvals workspace for capturing client approvals, status, visibility, response details, and attachments.

## Where to manage approvals (planner side)
- Event sidebar: **Approvals**.
- Includes list, create, edit, detail, delete, and clear-response actions.

## What data is tracked
- Title
- Summary
- Instructions
- Status
- Client visibility toggle
- Client responder name and note
- Acknowledged timestamp
- Attachments

## Client-facing behavior
- Client portal has approvals index/show routes.
- Client can accept/respond where visibility and portal access allow.

## Operator workflow
1. Create approval and set instructions.
2. Toggle visibility when ready for client.
3. Review response details on the approval detail page.
4. Clear stored response when needed (audit reset use case).
5. Manage supporting files in attachments.
