# Text Page Template

## What this feature is
A general-purpose generated-doc section for freeform content using markdown.

## Where to use it
- Event sidebar: **Packets** (Generated Documents builder).
- In “Add branded section,” select **Text Page**.

## What it is for
Use this when content does not fit a rigid layout, for example:
- policy pages
- prep instructions
- FAQ-style notes
- custom run sheets

## Editing experience
- Inline markdown editor in the segment form.
- Large-editor modal available for longer writing sessions.
- Segment preview and PDF render paths match other branded sections.

## Markdown guidance
- Supports standard markdown basics (headings, lists, links, emphasis, blockquotes).
- For a non-technical primer, use the Markdown Guide: https://www.markdownguide.org/basic-syntax/
- Also supports the packet’s custom `:::columns` / `:::column` pattern used by generated templates.

## Operator workflow
1. Add a Text Page segment.
2. Enter your content in markdown.
3. Preview for layout quality.
4. Render and validate in final packet order.
