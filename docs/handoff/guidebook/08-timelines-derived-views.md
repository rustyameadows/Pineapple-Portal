# Timelines (Derived Views)

## Purpose
Create focused timelines from ROS using tag filters and visibility controls.

## View fields/options
- `name`
- `slug`
- `description`
- `hide_locked` (boolean)
- `client_visible` (boolean)
- `tag_filter` (array of tag IDs)

## Typical uses
- Decision calendar view
- Vendor-specific timeline
- Ceremony-only timeline

## Default timelines
There is an “add defaults” flow that creates common views when required tags exist.
