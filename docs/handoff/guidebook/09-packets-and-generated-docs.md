# Packets & Generated Docs

## Purpose
Build branded client/staff packets from reusable sections and uploaded PDFs.

## Main workflow
1. Create/open generated document.
2. Add segments (PDF or branded section).
3. Order segments.
4. Preview and render.
5. Publish/share as needed.

## Branded section examples
- Event Overview
- Text Page
- Planning Team
- Timeline Snapshot
- Run of Show
- Cover Sheet
- Section Break

## Operator tip
Use Event Overview for structured event-info pages and Text Page for freeform narrative content.
