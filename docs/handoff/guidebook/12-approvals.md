# Approvals

## Purpose
Track client approvals with status, instructions, responses, and attachments.

## Main fields
- `title`
- `summary`
- `instructions`
- `client_visible`
- `status`
- `client_name`
- `client_note`
- `acknowledged_at`

## Main actions
- create/edit/delete approval
- clear stored client response
- manage related attachments

## Client side
Clients can view/respond to portal-visible approvals.
