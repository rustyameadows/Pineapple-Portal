# Payments (Cleaned Up)

## What this feature is
A cleaned-up payment schedule area with clearer list/detail flows for planner-side financial milestones.

## Where to manage payments (planner side)
- Event sidebar: **Payments**.
- Includes list, create, edit, detail, and delete.

## What data is tracked
- Title
- Amount
- Due date
- Description
- Status
- Client visibility toggle
- Paid dates and optional client note fields

## Client-facing behavior
- Client portal includes financial index + payment detail route.
- Clients can mark a payment paid on the payment route when exposed.

## Operator workflow
1. Add milestone payments with due dates and amounts.
2. Mark client visibility when appropriate.
3. Update status over time as payments progress.
4. Keep notes attached to each payment item for context.
