# Event Information Template (Event Overview)

## What this feature is
The generated-doc template type for Event Information is now represented as **Event Overview**, a structured branded section using markdown body content.

## Where to use it
- Event sidebar: **Packets** (Generated Documents builder).
- In “Add branded section,” select **Event Overview**.

## What it is for
A polished event information packet page with starter content blocks for:
- important information
- timeline highlights
- planner contacts
- vendor contacts
- social/parking notes

## Authoring behavior
- Uses markdown body content stored in segment source options.
- Ships with a substantial default starter body for quick editing.
- Supports the custom two-column markdown block used by the generated renderer.

## Operator workflow
1. Add an Event Overview segment.
2. Replace starter text with event-specific content.
3. Reorder segment in the packet.
4. Preview and render PDF.
