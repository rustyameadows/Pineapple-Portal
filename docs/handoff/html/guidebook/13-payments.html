# Payments

## Purpose
Track payment milestones and client-facing financial status.

## Main fields
- `title`
- `amount`
- `due_on`
- `description`
- `client_visible`
- `status`
- `paid_at`
- `paid_by_client_at`
- `client_note`

## Main actions
- create/edit/delete payment
- update status over time
- client can mark payment paid in portal when exposed
