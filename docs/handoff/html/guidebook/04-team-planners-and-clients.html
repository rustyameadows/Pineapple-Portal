# Team (Planners + Clients)

## Purpose
Manage who can work internally and who can access the portal.

## Planner team (event settings → Planners)
- Add existing planner users to event.
- Order planners.
- Mark lead planner.
- Toggle client visibility for planners shown externally.

## Client team (event settings → Clients)
Two paths:
1. Invite new client (creates user + access)
2. Grant existing client user access

## Client access details
- Client reset links are generated and can be copied.
- UI shows reset expiry countdown and disables copy when expired.

## Useful fields/options
Event team member supports:
- `member_role` (planner/client)
- `client_visible`
- `lead_planner`
- `position`
