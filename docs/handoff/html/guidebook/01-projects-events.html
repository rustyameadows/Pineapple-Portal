# Projects (Events)

## What “Project” means here
In Pineapple Portal, a project is an **Event** record.

## Main pages
- Events index (active + archived lists)
- Event detail page
- Event settings page

## Event lifecycle
- Create event.
- Work event while active.
- Archive when complete.
- Restore if re-opened.

## Key event fields (create/update)
- `name` (required)
- `starts_on`
- `ends_on`
- `location`
- `location_secondary`
- `portal_slug`
- `event_photo_document_id`
- `financial_payments_enabled`

## Operator notes
- Events are split into active/archived sections in the main list.
- Archive/restore actions are available directly from Events list actions.
